# Лабораторна робота №6: C++ openCV

## Опис завдання
Створити С++ програму, яка відображає відео з камери у вікні, з різними режимами обробки зображень в залежності від настинутих клавіш, реагує на клавіатури та мишку.

## Вимоги:
1. Використати openCV (інші бібліотеки за бажанням).
2. Програма має мати модульну архітектуру (кожен модуль — окремий клас в окремих файлах .hpp та .cpp).
3. Білд за допомогою CMake + make
4. Зручний білд-скрипт (build.sh), в якому будуть міститись всі необхідні команди для компіляції
5. Зручний скрипт попереднього встановлення (preinstall.sh), який буде містити всі команди, необхідні для білда і запуску вашої програми на іншому комп’ютері. Наприклад, встановлення бібліотек та білд системи:
6. $ sudo apt install libopencv-dev cmake gcc -y
7. Зручний скрипт запуску (run.sh), який буде запускати вашу програму
8. В readme.md в директорії з програмою, описати інструкції для білду і запуску, а також вимоги до операційної системи та заліза.

## Вимоги до системи
* **Операційна система:** Linux

## Інструкція із запуску
1. Відкрити термінал у теці `Lab6`.
2. Виконати наступну команду для завантаження:
 `./preinstall.sh`
3. Виконати build.sh для компіляції:
 `./build.sh`
4. Виконати запуск програми:
 `./run.sh`
