# Лабораторна робота №6: C++ openCV

## Опис завдання
Освоїти роботу з cv::dnn (Deep Neural Networks) для детекції об'єктів. Зрозуміти проблему блокування інтерфейсу важкими обчисленнями та вирішити її за допомогою std::thread та std::mutex, або std::condition_variable.
## Коротки опис архітектури
### main.cpp

**Роль:** Головна точка входу (Entry Point).

Опис: Ініціалізує всі об'єкти, містить нескінченний цикл обробки кадрів (while), керує станом інтерфейсу користувача (створення вікон, реєстрація колбеків миші onMouse та трекбару для яскравості). Передає дані між об'єктами.

### CameraProvider

**Роль:** Постачальник відеокадрів.

Опис: Обгортка над cv::VideoCapture. Відповідає за підключення до веб-камери (зазвичай пристрій 0), перевірку її статусу та зчитування свіжих кадрів (getFrame()).

### FrameProcessor

**Роль:** Обробник зображень.

Опис: Виконує безпосередню трансформацію матриці кадру cv::Mat. Містить логіку різних режимів відображення: інверсія кольорів, Gaussian Blur, Canny Edges, ефект Glitch, трансформації (зум/поворот) та малювання рамок.

### Display

**Роль:** Відмальовувач інтерфейсу.

Опис: Обгортка над функціями cv::imshow та cv::namedWindow. Займається виключно виведенням готового (вже обробленого) кадру на екран монітора.

### KeyProcessor

**Роль:** Обробник клавіатури.

Опис: Аналізує код натиснутої клавіші. Відповідає за перемикання режимів роботи (збереження currentMode) та встановлення прапорця виходу (exitPressed), якщо користувач натиснув Esc або q.

### FaceDetector

**Роль:** Асинхронний детектор облич (DNN).

Опис: Використовує нейромережу Caffe (cv::dnn) для пошуку облич на кадрі. Щоб уникнути зависання інтерфейсу (просадки FPS під час важкого інференсу net.forward()), працює в окремому фоновому потоці (std::thread). Використовує std::mutex для безпечного оновлення списку знайдених облич (рамок) та передачі їх в основний потік для відмальовки.

1. Відкрити термінал у теці `Lab7`.
2. Виконати наступну команду для завантаження:
* `./preinstall.sh`
3. Виконати build.sh для компіляції:
 `./build.sh`
4. Виконати запуск програми:
 `./run.sh`
5. Для вмикання режиму `Face Detection` натисніть "6" на клавіатурі.
