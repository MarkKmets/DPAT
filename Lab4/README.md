# Лабораторна робота №4. Візуалізація даних 2

## Опис завдання
Створити програму, яка дозволить малювати графік функції гармоніки з накладеним шумом та надавати можливість змінювати параметри гармоніки та шуму за допомогою інтерактивного інтерфейсу, що містить слайдери, кнопки та чекбокси. Зашумлену гармоніку відфільтруйте за допомогою фільтру (Був використаний низькочастотний фільтр Баттерворта, butter()). 

## Візуалізація
### Було реалізовано наступні функції:
* **`get_noise(mean, cov)`**
    Генерує масив випадкового білого шуму на основі заданого середнього значення (`mean`) та дисперсії (`cov`). Має вбудований механізм кешування: генерує новий масив лише у випадку зміни параметрів шуму, що запобігає небажаному "мерехтінню" при зміні лише параметрів самої гармоніки.

* **`apply_filter(data, cutoff)`**
    Застосовує цифровий низькочастотний фільтр Баттерворта 3-го порядку до переданих даних. Використовує функцію `scipy.signal.filtfilt` для прямо-зворотної фільтрації, що забезпечує нульовий фазовий зсув (відфільтрована лінія не зсувається у часі). Частота зрізу регулюється параметром `cutoff`.

* **`harmonic_with_noise(amp, freq, phase, noise_mean, noise_cov, cutoff)`**
    Головна функція генерації сигналів. Створює "чисту" синусоїду за заданими параметрами амплітуди, частоти та фази, викликає `get_noise` для отримання шуму, накладає його на гармоніку та пропускає через `apply_filter`. 
    **Повертає три масиви даних:** чистий сигнал, зашумлений сигнал та відфільтрований сигнал.

### Функції графічного інтерфейсу (GUI)

* **`update(val)`**
    Функція-обробник (callback) для слайдерів. Викликається щоразу, коли користувач рухає будь-який повзунок. Отримує нові значення, передає їх у `harmonic_with_noise` та миттєво перемальовує графіки з новими даними, динамічно підлаштовуючи масштаб осі Y.

* **`reset(event)`**
    Обробник події для кнопки "Reset". Скидає значення всіх слайдерів інтерфейсу до їхніх початкових (дефолтних) налаштувань.

* **`toggle_noise(label)`**
    Обробник події для чекбокса "Show Noise". Змінює стан видимості лінії зашумленого графіка (вмикає або вимикає його відображення на полотні).

## Вимоги до системи
* **Операційна система:** Windows, macOS, Linux
* **Версія інтерпретатора:** Python 3.9+
* **Залежності:** Необхідні бібліотеки (`matplotlib`, `numpy` і тд.) прописані в файлі `requirements.txt`.

## Інструкція із запуску
1. Створіть та активуйте віртуальне середовище: `python -m venv venv`
2. Встановіть необхідні залежності: `pip install -r requirements.txt`
3. Запустіть програму: `python program.py`
4. Можете успішно використовувати програму.
