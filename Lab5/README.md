# Лабораторна робота №5. Наука про дані: обмін результатами та початковий аналіз


## Опис завдання
Створити веб-додаток, для візуалізації та аналізу даних VHI по областях України. Створити два dropdown списки, два sliders, створити таблицю та графіки для візуалізації відфільтрованих даних.

## Основні функції
### Автоматичне завантаження даних: Використання urllib для отримання актуальних CSV-файлів по 27 адміністративних одиницях України.

### Інтерактивна фільтрація:

* **Вибір індексу (VCI, TCI, VHI).**

* **Вибір області України.**

* **Слайдери для налаштування часових інтервалів (роки та тижні).**

* **Можливість сортування даних за значеннями індексів.**

### Візуалізація:

* **Табличне відображення відфільтрованих даних.**

* **Лінійний графік динаміки обраного індексу для конкретної області.**

* **Гістограма для порівняння середніх значень індексів по всіх областях.**

### Керування станом: Кнопка "Скинути фільтри" для миттєвого повернення до початкових налаштувань.

## Вимоги до системи
* **Операційна система:** Windows, macOS, Linux
* **Версія інтерпретатора:** Python 3.9+
* **Залежності:** Необхідні бібліотеки (`streamlit`, `plotly` і тд.) прописані в файлі `requirements.txt`.

## Інструкція із запуску
1. Створіть та активуйте віртуальне середовище: `python -m venv venv`
2. Встановіть необхідні залежності: `pip install -r requirements.txt`
3. Запустіть програму: `streamlit run program.py`
4. Можете успішно використовувати програму.
